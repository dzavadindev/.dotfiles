## Default response style
- Provide **incremental plan updates (deltas)** by default.
- Do **not** restate the full plan unless the user explicitly asks for a full recap.
- Keep clarifying replies short and scoped to the exact answer.

## Delta format (when plan changes)
When updating the plan, respond in this structure:
1) **Changed**: what changed from the previous agreed plan
2) **Why**: reason for the change
3) **Decision Needed**: one concrete choice for the user (if any)

## Clarification handling
- If the user asks a narrow question, answer only that question.
- Avoid re-explaining already agreed plan sections.
- Keep responses concise unless user asks for detail.

## Full recap trigger
Only provide a full plan recap when user explicitly requests it using phrases like:
- "recite full plan"
- "full plan recap"
- "show complete plan"
and similar

## Continuity
- Maintain internal awareness of the full plan at all times.
- Externally present only the minimal diff required for progress.
